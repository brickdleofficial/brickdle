BRICKMYSTERY v2 — Daily LEGO set comparison guessing game

HOW TO PLAY
1. Open index.html in any modern browser.
2. Select a set from the autocomplete list and submit.
3. Use color-coded theme/year/piece-count comparisons to solve in six guesses.
4. A new daily puzzle appears at 00:00 UTC. Practice mode is unlimited.

HOW TO PUBLISH
Upload index.html to a static hosting service such as GitHub Pages or Cloudflare Pages.
No build tools, accounts, backend, or API keys are required.

NOTES
- The catalogue is a curated starter dataset of 79 sets, and the daily sequence repeats after 79 days. Expand and verify data before a public launch.
- All users share a UTC daily answer. Practice puzzles are random.
- Stats and daily guesses are stored locally in the browser (localStorage), not synced across devices.
